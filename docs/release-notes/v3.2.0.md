# HGhubX v3.2.0

HGhubX 3.2.0 正式版：新增 MacCMS v10 订阅源导入与端到端可用性探测、自定义跳过片头与 5 秒可取消跳过片尾倒计时、缓冲实时网速、全量诊断日志原生分享与按源分桶片库，同时修复切源后线路与个人页错乱、地区受限/超时源长时间无提示转圈、移动端液态玻璃底栏与侧滑返回及平板/鸿蒙交互问题；覆盖 Windows、macOS、Linux、Android、iOS 与 HarmonyOS。

## 新增与优化
1. **MacCMS v10 订阅清单导入与端到端测活（#309）**：在「设置 → 视频源管理」与首启「导入视频源」支持导入 Base58 / Base64 / JSON（`{ api_site }`）及 TVBox `type: 1` 订阅清单，自动探测叶分类并隐藏空专题；新增「测试可用性」「停止测试」「一键选可用」「仅看可用」，端到端实测接口与直链片源连通性并实时反馈延迟与本地化失败原因；统一扫码与深链对订阅清单的识别，并对 TV / 局域网单源入口误传订阅清单提供明确引导；批量移除源新增内联二次确认并保持搜索筛选栏可见。
2. **自定义跳过片头与 5 秒可取消跳过片尾（#309）**：在「设置 → 播放设置」新增「跳过片头 / 跳过片尾」（`0–600s`、默认 `0`，支持快捷挡位与自定义秒数）；到达片尾跳过窗口时展示 5 秒可取消倒计时胶囊，支持随时「取消」本次跳过或「立即下一集」，跨集保留跳过提示。
3. **缓冲实时网速与限区/超时快速提示（#309）**：Rust 媒体代理层流式统计接收速率，在缓冲转圈下方按需展示实时网速（持续 `0 KB/s` 超过 2.5 秒置琥珀色提示）；媒体代理透传上游 `403`/`404`/`410`/`451`，并将 22 秒内未响应的黑洞或限区请求收口为 `504`，前端对 `403`/`451` 与 `504` 清单超时快速失败并提示切换网络或视频源，同时保留 `404`/`410` 的 4 次有界恢复契约。
4. **全量诊断日志一键原生分享（#309）**：在「设置 → 播放与网络诊断」新增「分享全量诊断日志」，打通 Android（`FileProvider` + 系统分享面板）、iOS / iPadOS（原生 `UIActivityViewController`）、HarmonyOS（含鸿蒙 PC 原生分享/保存桥接）与桌面端导出；本地化日志导出与分享报错，修复移动端失败时误报「已保存」及私有路径暴露。
5. **按源分桶的本地片库与全端交互打磨（#309）**：未登录本地片库（`hghubx_source_library_v1`）按当前视频源独立隔离，避免切源后收藏与历史串源；移动端浮空导航栏升级液态玻璃材质与动态高光（支持系统降低透明度与高对比度自动回退），左缘侧滑返回支持动态跟手并反显真实上一页预览，显著优化页签滑切顺滑度。

## 修复
1. **切换自定义源回主源后个人页报错（#309）**：跨源共享 `TRUSTED_MIRRORS` 且未恢复目标源持久化线路 -> 按 `source_id` 隔离镜像与线路状态，切回主源时自动恢复持久化线路并推进会话代次。
2. **地区受限或黑洞 CDN 长时间卡在「正在加载 · 0 KB/s」（#309）**：上游长时间无响应触发 Android `wry` 自定义协议 30 秒通道超时丢响应，导致前端持续重试 -> 将 Rust 媒体抓取总超时收口至 22 秒并映射为 HTTP `504`，前端 24 秒清单超时内快速弹出地区或网络受限提示。
3. **移动端、平板与鸿蒙平台边界交互问题（#309）**：修复平板横屏误触发强制旋转全屏、宽屏长按倍速引导弹窗布局、长作者名溢出、鸿蒙首启协议与全栈返回键拦截，以及左缘侧滑返回与页内横滑/底层搜索的手势冲突。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb` 与 `.rpm`；Android 提供按 ABI 分包签名 APK（`versionCode=3002000`）；iOS 提供已 ad-hoc 签名的 `.ipa`（需自行重签侧载安装）；HarmonyOS 提供未签名的 `HGhubX_3.2.0_ohos_arm64_unsigned.hap`（需自行签名后安装）。
- 支持从 `v3.0.0`–`v3.1.2` 直接覆盖安装，所有已导入的视频源、收藏、观看记录与偏好设置均予保留。
