# HGhubX TV tv-v3.2.0

HGhubX TV 3.2.0 正式版（`com.hghubx.tv`）：新增自定义跳过片头与 5 秒可取消跳过片尾倒计时、缓冲实时网速、限区/超时快速错误提示、按源分桶本机片库、源自定义默认排序标签与详情页「简介」全文弹窗，并完善遥控器焦点与批量管理交互。

## 新增与优化
1. **自定义跳过片头与 5 秒可取消跳过片尾（#309）**：在 TV「设置 → 播放设置」新增「跳过片头 / 跳过片尾」（`0–600s`，关闭自动续集时明确提示依赖关系）；进入片尾跳过窗口时展示 5 秒可取消倒计时提示条，按遥控器返回键即可取消本次跳过，亦可立即切换至下一集。
2. **缓冲实时网速与限区/超时快速提示（#309）**：加载状态条按需显示媒体代理实时速率（连续 `0 KB/s` 超过 2.5 秒置琥珀色提示）；后端透传 `403`/`404`/`410`/`451` 并将黑洞/限区请求收口在 22 秒内返回 `504`，快速给出地区限制或切源提示。
3. **按源隔离片库、源自定义排序与详情页「简介」全文弹窗（#309、#310）**：TV 本机 IndexedDB 收藏与观看历史按视频源独立分桶，支持按当前源清空历史；首页片架与分类浏览支持源声明的 `{ key, name, default? }` 自定义排序与默认项；详情页新增遥控器可上下滚动的「简介」全文弹窗，长简介阅读更清晰。

## 修复
1. **TV 端地区不可用或黑洞源长期无报错提示（#309）**：此前上游超长超时触发 Android `wry` 30 秒通道超时丢响应，导致播放器长期停留在「正在加载 · 0 KB/s」 -> 后端 22 秒总截止返回 `504`，前端立即弹出地区或网络受限提示。
2. **批量移除报错遮挡与清空历史弹窗标题不统一（#309）**：修复片库批量移除失败时错误提示被确认弹窗遮挡的问题，统一清空历史弹窗标题；TV / 局域网推源入口收到多站点订阅清单时给出明确引导提示。

## 安装与兼容提示
- Android TV 按 ABI 分包提供 `HGhubX-TV_3.2.0_arm64.apk`、`HGhubX-TV_3.2.0_arm.apk`、`HGhubX-TV_3.2.0_x86_64.apk`（`com.hghubx.tv`，`versionCode=3002000`）。
- 沿用与既有 `com.hghubx.tv` 相同的签名证书与单调递增 `versionCode`，支持从 `tv-v3.0.0`–`tv-v3.1.2` 直接覆盖安装，保留已导入视频源、本机片库、观看记录、启动 PIN 与偏好设置。
